## Citation discipline

- Cite the primary paper or proceedings record when available.
- Cite the Stanford blog as a technical report/blog, not as a peer-reviewed paper unless a formal publication is identified.
- Record version, date accessed and DOI/arXiv identifier where applicable.
- Never cite a search-result snippet as the sole evidence for a technical claim.
- Add a source only after checking its authorship, publication status and claims.
